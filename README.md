# TRACE_Model
Numerical implementation of TRACE (Temporal Recording through Arrested Coupled Evolution) for simulating hierarchical patterns via history-dependent front propagation and arrest

This repository contains the simulation codes used in the manuscript:

"Geometric origin of hierarchical patterns through history-dependent growth and arrest"
DOI: 10.26434/chemrxiv-2026-5sdw8

## Requirements
- Python 3.x
- NumPy
- Matplotlib
