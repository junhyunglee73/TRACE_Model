# TRACE_Model
Numerical implementation of TRACE (Temporal Recording through Arrested Coupled Evolution) for simulating hierarchical patterns via history-dependent front propagation and arrest

This repository contains the source code for the TRACE model, a minimal theoretical framework designed to reveal the geometric origin of hierarchical patterns in non-diffusive systems. 

### Key Features * Diffusion-free patterning: Patterns emerge from the competition between front propagation and kinetic arrest rather than material transport. * Spatio-temporal recording: The model encodes growth history into a spatial record, establishing hierarchy through history-dependent exclusion. * Diverse Morphologies: Successfully reproduces cell-like domains, stripes, banded structures, and boundary-driven inward growth.
